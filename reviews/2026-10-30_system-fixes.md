## 1. 欠損価格を割高評価していた問題

- DCF・感応度分析・統合判定で、欠損・NaN・無限大・ゼロ以下の価格を「評価不能」とする。価格不正時は財務情報取得前に打ち切る。
- 非有限の上値余地をスコアに変換しない。統合分析でも非有限・評価不能な結果を採用しない。
- 不正な評価キャッシュは再利用・保存しない。現在価格が不正なら、正常な過去評価がキャッシュされていても採用しない。
- 価格キャッシュの無限大も除外。通常の前回正常価格の表示用フォールバックは維持する。
- 最新OHLCを検証。定時処理では価格の日付も予定営業日と一致していることを確認する。取得失敗銘柄の売買・ストップ更新は保留する。

## 2. PAPERの長時間遅延・取りこぼし

| 対象 | 制限・動作 |
|---|---|
| 全銘柄価格取得 | 4並列、1銘柄20秒、全体300秒 |
| CoCh用価格取得 | 従来の3か月期間を維持、全体60秒 |
| メイン処理 | 最大900秒 |
| 定時セッション | 画面生成・公開を含め期限1200秒。その他コマンドは原則300秒以内 |
| 起動遅延 | 予定時刻から60分超は要確認として実行しない |
| 二重起動 | 待ち行列に入れず終了。失敗済み処理も自動再実行しない |
| 日付またぎ・実行期限超過 | データ取得と台帳保存時にもチェックして停止 |
| 買い注文 | シグナル翌営業日を過ぎた未約定注文は取消・要確認。後日の始値で約定しない |
| 独立監視 | 既存10:30・17:00に加え15分間隔。直近7暦日の営業日を点検 |

監視は各予定時刻から50分後以降の未完了処理を一度だけ通知する。完了確認・通知記録は同じロック内で更新し、本処理と競合して完了状態を巻き戻さない。

期限超過時は対象コマンドのプロセスグループを停止する。ただし途中まで保存済みの売買を巻き戻す仕組みではないため、失敗後は台帳とログを確認してから判断する。
